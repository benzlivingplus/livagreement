# LIV Agreement

ระบบสร้างสัญญาเช่าบ้าน 3 ภาษา (จีน / อังกฤษ / ไทย) ของ THE LIVING PLUS

- กรอกเฉพาะข้อมูลที่เปลี่ยน (ผู้ให้เช่า ผู้เช่า ที่อยู่ วันที่ ค่าเช่า เงินประกัน เงื่อนไขเสริม) แล้วสัญญาจะอัปเดตทันที
- รองรับสัญญาใหม่และสัญญาต่ออายุ (ใช้เงินประกันเดิม จ่ายค่าเช่าล่วงหน้าก้อนเดียว)
- เงื่อนไขเปิด/ปิดได้: ภาษีหัก ณ ที่จ่าย 5%, ภาษีบ้าน, ล้างแอร์โดยเจ้าของ, ค่าอินเทอร์เน็ต, ข้อ 13 คุ้มครองผู้เช่า, การใช้งาน (อยู่อาศัย / อยู่อาศัยและประกอบกิจการ)
- พิมพ์ / บันทึกเป็น PDF จากเบราว์เซอร์ หรือดาวน์โหลดไฟล์ PDF ได้ทันที ไม่ต้องผ่าน Word
- ระบบเก็บสัญญา: ตั้งชื่อไฟล์, บันทึก, เปิด, ลบ, ค้นหา, สำรอง/นำเข้าข้อมูล (.json)

ข้อมูลสัญญาเก็บใน localStorage ของเบราว์เซอร์แต่ละเครื่อง ใช้ปุ่ม "สำรองข้อมูลทั้งหมด" เพื่อย้ายเครื่องหรือกันข้อมูลหาย

ไฟล์เดียว: `index.html` เปิดผ่าน GitHub Pages ได้เลย
